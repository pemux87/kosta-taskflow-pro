# 01. Product — 제품 정의

## 목표

> **"지금 누가 뭐 해?"** 라는 질문이 사라지게 만든다.

팀 업무를 실시간으로 시각화하여, 별도 보고 없이도 팀 전체의 진행 상황을 한눈에 파악할 수 있는 환경을 만든다.

---

## 페르소나

| 항목 | 내용 |
|---|---|
| 대상 | 10명 규모 스타트업의 팀리더 |
| 연령대 | 30~40대 |
| 상황 | 매일 아침 "지금 뭐 하고 있어요?" 를 팀원에게 직접 물어봐야 하는 상황 |
| 목표 | 묻지 않아도 팀 전체 업무 현황을 파악하고 싶다 |

---

## MVP 범위

### CRUD 4종 — 모두 화면에서 동작

| 동작 | 설명 |
|---|---|
| 추가 (Create) | 폼 입력 후 태스크 생성 |
| 목록 (Read) | 전체 태스크 목록 조회 및 필터링 |
| 수정 (Update) | 인라인 또는 모달로 내용·상태 변경 |
| 삭제 (Delete) | 확인 후 태스크 삭제 |

### 상태 분류

| 상태 값 | 표시 라벨 |
|---|---|
| `todo` | 할 일 |
| `in_progress` | 진행 중 |
| `done` | 완료 |

### 마감 시각 (due_at)

- 날짜 + 시간까지 지정 및 표시
- 예시: `2026-05-12 18:00`
- 마감 1시간 이내 항목은 시각적으로 강조 표시

### 테마

- 라이트 / 다크 테마 토글
- 설정은 `localStorage`에 유지 (새로고침 후에도 복원)

### 반응형

- 모바일 360px 이상에서 레이아웃 깨짐 없이 동작
- 데스크탑 우선 설계, 모바일은 단일 컬럼 레이아웃으로 전환

## UI 톤 — macOS 스타일

| 요소 | 적용 기준 |
|---|---|
| 모서리 | 둥근 모서리 (`border-radius: 12px` 이상) |
| 그림자 | 부드러운 그림자 (`box-shadow` 다단 레이어) |
| 카드 | 반투명 배경 (`backdrop-filter: blur`) |
| 폰트 | 시스템 폰트 (`-apple-system, BlinkMacSystemFont, 'Segoe UI'`) |

## 확장 계획 (MVP 이후)

MVP 완료 후 아래 순서로 단계적으로 확장한다.

1. JWT 로그인 / 회원 인증
2. 팀 · 멤버 관리
3. Kanban 보드 (드래그 앤 드롭)
4. 팀 채팅
5. CI/CD 파이프라인 구축

> **WebSocket**: MVP에서는 폴링(polling)으로 대체한다. 실시간 통신은 확장 단계에서 도입한다.

---

## 범위 외 (Out of Scope)

MVP 및 확장 계획 모두에 포함하지 않는다.

- 외부 결제 시스템
- 네이티브 앱 (iOS / Android)
- WebRTC (화상·음성 통화)
- 외부 캘린더 연동 (Google, Outlook 등)
- 파일 업로드

---

## 성공 기준

MVP가 완료되었다고 판단하는 조건은 아래 **5가지를 모두 충족**할 때다.

| # | 기준 | 측정 방법 |
|---|---|---|
| 1 | 새로고침 후에도 데이터 유지 | 브라우저 새로고침 시 태스크 목록 동일 표시 확인 |
| 2 | 360px에서 레이아웃 깨짐 없음 | Chrome DevTools 모바일 뷰 직접 확인 |
| 3 | API 응답 200ms 이하 | 로컬 환경 Network 탭 기준 |
| 4 | CRUD 4종 화면에서 모두 동작 | 추가·목록·수정·삭제 시나리오 수동 테스트 |
| 5 | 라이트 / 다크 테마 토글 작동 | 토글 후 새로고침해도 테마 유지 확인 |
