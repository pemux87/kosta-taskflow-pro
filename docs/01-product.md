# 01. Product — 제품 정의

## 타깃 사용자

| 구분 | 설명 |
|---|---|
| 주 사용자 | 5~50인 규모 팀의 팀장·팀원 |
| 사용 환경 | 데스크탑 브라우저 (Chrome, Edge 최신 버전) |
| 기술 수준 | 비개발자도 무리 없이 사용할 수 있는 수준 |
| 핵심 페인포인트 | 업무 현황이 분산되어 있어 진행 상태를 한눈에 파악하기 어렵다 |

---

## 핵심 기능 (Core Features)

### 1. 인증 (Authentication)
- 이메일 + 비밀번호 회원가입 / 로그인
- JWT 기반 세션 유지
- 로그아웃

### 2. 프로젝트 관리 (Project)
- 프로젝트 생성 · 수정 · 삭제
- 프로젝트별 멤버 초대 및 역할 부여 (`owner` / `member`)

### 3. 태스크 관리 (Task)
- 태스크 생성 · 수정 · 삭제
- 상태 변경: `todo` → `in_progress` → `done`
- 담당자 지정, 마감일 설정
- 태스크 목록 필터링 (상태 / 담당자 / 마감일)

### 4. 칸반 보드 (Kanban Board)
- 상태별 컬럼으로 태스크 시각화
- 드래그 앤 드롭으로 상태 변경

### 5. 대시보드 (Dashboard)
- 내 태스크 요약 (전체 / 진행 중 / 완료)
- 마감 임박 태스크 목록

## 비기능 요구사항 (Non-functional Requirements)

| 항목 | 기준 |
|---|---|
| 응답 속도 | API 응답 95th percentile 500ms 이하 |
| 인증 보안 | JWT 만료 1시간, Refresh Token 7일 |
| 접근 제어 | 프로젝트 멤버가 아닌 사용자는 해당 프로젝트 데이터에 접근 불가 |
| 반응형 | 모바일 레이아웃은 MVP 이후 대응 (현재 데스크탑 우선) |
| 브라우저 지원 | Chrome 120+, Edge 120+ |

---

## MVP 범위 (Out of Scope)

아래 항목은 MVP에 포함하지 않는다.

- 실시간 알림 (WebSocket)
- 파일 첨부
- 댓글 기능
- 외부 서비스 연동 (Slack, Jira 등)
- 모바일 앱
